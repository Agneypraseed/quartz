Think of a verb as having:

- a **stem** (the main part)
- an **ending** (which changes)

For **spielen**

❌ **Wir bist Studenten.**

This is wrong because:

- **wir** = we
- **bist** is only used with **du**

The correct sentence is:

✅ **Wir sind Studenten.** -> We are students.

**gern** = gladly / like to

Use **gern** with verbs:
- Ich spiele gern Fußball.
- Ich schaue gern Filme.

Use **nicht so gern**:
- Ich spiele nicht so gern Tennis.
- Ich schaue nicht so gern Horrorfilme.

German has a preferred word order.

The usual order is:

> **Subject → Verb → Time/Frequency → Object**

| Ich spiele gern Fußball. | I like playing football.   |     |
| ------------------------ | -------------------------- | --- |
| Ich spiele oft Fußball.  | I often play football.     |     |
| Ich lese gern Bücher.    | I like reading books.      |     |
| Ich lese oft Bücher.     | I often read books.        |     |
| Ich höre gern Musik.     | I like listening to music. |     |
| Ich höre oft Musik.      | I often listen to music.   |     |
| Ich schaue gern Filme.   | I like watching movies.    |     |
| Ich schaue oft Filme.    | I often watch movies.      |     |
Ich + Verb + oft/manchmal/selten/nie + Objekt

- **lese** = read (from **lesen**)
- **Bücher** = books
